# Глобальные трекеры для Transmission

[English](../../README.md)

Проект собирает публичные BitTorrent-трекеры из нескольких источников, удаляет дубликаты, ежедневно проверяет доступность и создаёт оптимизированные списки для Transmission 4.1+.

- [`balanced`](../../lists/transmission/balanced.txt) — рекомендуемый повседневный профиль: несколько параллельных уровней и резервные трекеры.
- [`aggressive`](../../lists/transmission/aggressive.txt) — временный профиль для редких или слабых раздач.
- [`all`](../../lists/transmission/all.txt) — все проверенные на данный момент UDP-, HTTP- и HTTPS-трекеры.
- [`candidates`](../../lists/candidates/all.txt) — полный каталог, включая временно недоступные адреса.

Добавить трекеры в magnet-ссылку:

```bash
python3 scripts/boost_magnet.py --profile balanced 'magnet:?xt=urn:btih:...'
```

Приватные трекеры с личными passkey не публикуются. Статус «Alive» означает только корректный ответ при последней проверке и не гарантирует наличие пиров или полного сида для конкретной раздачи.
